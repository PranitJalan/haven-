# Riposte

A 2D platformer where you carry no weapon of your own.

Everroot is the last forest that still remembers how to grow, and the
machines have come to harvest what it remembers. You are what the forest
kept. You cannot strike first — you can only send back what is sent at you.

Raise the shield to reflect a rocket into the machine that fired it. The
katana cuts rockets out of the air and chips the smaller machines, but a
Warden's plating turns it, so a boss can only be opened with its own fire.

## Controls

| | |
|---|---|
| `A` / `D` | move |
| `W` / `Space` | jump |
| `Shift` | shield |
| `J` / `K` / `X` / left click | katana |
| `R` | restart level |
